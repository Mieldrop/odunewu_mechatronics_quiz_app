# Mechatronics Quiz App

## What it does
The Mechatronics Quiz App is a Python multiple-choice quiz that tests basic knowledge of electronics, electrical systems, and mechatronics. Users choose an easy, medium, or hard difficulty level, answer questions, and receive their score, percentage, and a performance message.

## How to run it
1. Install Python 3.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run:

```bash
python mechatronics_quiz_app.py
```

## My own twist
I added difficulty levels (easy, medium, and hard) so users can choose the challenge they want. The app also reviews incorrectly answered questions and provides explanations after the quiz, helping users learn from their mistakes.
